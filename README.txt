PIXFLOW WEBSITE — QUICK START (ANDROID)

Included:
- index.html: the complete responsive one-page website.
- images/: add your own photos here (optional for now).

HOW TO PREVIEW ON ANDROID:
1. Download and extract PixFlow_Website.zip.
2. Open index.html using a browser or an HTML editor app that can preview HTML.
3. The first version uses abstract CSS artwork as placeholders; it does not contain your personal photos yet.

HOW TO PUBLISH FOR FREE:
A beginner-friendly option is GitHub Pages, which can host a static website for free.
1. Create/sign in to a GitHub account in your phone browser.
2. Create a new public repository named pixflow-portfolio.
3. Upload index.html (and any images you add).
4. In repository Settings > Pages, select Deploy from a branch, choose main and /(root), then Save.
5. Wait for GitHub Pages to publish and open the provided website URL.

BEFORE PUBLISHING:
- Replace YOUR-EMAIL@example.com with your real contact email.
- Change the Pinterest button link to your own Pinterest profile.
- Replace the abstract portfolio placeholders with your own photos.
- Only publish photos you own or have permission to use.

No paid domain or hosting is required for the starter version.
